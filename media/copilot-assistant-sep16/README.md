# Composer controlled CopilotKit Assistant

![Gallery draft to Assistant update, in light and dark themes](copilot-assistant.gif)

Production-build browser recording, September 16, 2026. Select a Gallery Text example, edit it, open the same draft in Composer, and send an Assistant prompt. The canvas and JSON update together; the panel follows the theme toggle.

The model response uses a deterministic local Gemini SSE fixture. The request is checked for the edited canvas and selected catalog. No real model request or API key is used. The recording completed without browser console or page errors.

The application uses CopilotKit presentation with Composer's existing chat coordinator, history, validation, and renderer. The GIF is 1200 × 800, 10 fps, 9.4 seconds.
